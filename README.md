## Tools Used

| Tool | Website | Description |
| --- | --- | --- |
| **Autopsy** | [Autopsy](https://www.autopsy.com/) | Digital forensics software for examining disk images and recovering artifacts such as user activity, email records, and deleted files. |
| **Registry Explorer** | [Eric Zimmerman's Tools](https://ericzimmerman.github.io/) | Examines Windows Registry hives to help reconstruct system configuration and user activity. |
| **Windows Event Viewer** | [Microsoft documentation](https://learn.microsoft.com/en-us/windows/win32/eventlog/event-logging) | Displays Windows event records useful for investigating authentication and system activity. |
| **Wireshark** | [Wireshark](https://www.wireshark.org/) | Captures and analyzes network packets to investigate protocols and traffic behavior. |
| **Nessus** | [Tenable Nessus](https://www.tenable.com/products/nessus) | Scans systems for known vulnerabilities and helps prioritize remediation. |
